## ⚡ CHẠY CHƯƠNG TRÌNH BẰNG 1 NÚT (1-CLICK RUN)

Bạn có 2 cách cực kỳ đơn giản để chạy toàn bộ hệ thống (Backend + Frontend + Tự mở trình duyệt):

### Cách 1: Kích đôi chuột (Double-Click)
- Mở thư mục `E:\Kiểm thử phần mềm`
- Click đúp vào file **`CHAY_NGAY.bat`** (hoặc `run.bat`)
- *Hệ thống sẽ tự động bật Backend, Frontend và mở ngay trang web `http://localhost:3000` trên trình duyệt của bạn!*

### Cách 2: Chạy 1 lệnh từ bất kỳ đâu
Mở Terminal/CMD và gõ:
```cmd
E: & cd "E:\Kiểm thử phần mềm" & run.bat
```
